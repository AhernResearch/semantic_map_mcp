### 检索耗时拆分

单查询搜索约759毫秒 = 原始召回约30.65毫秒 + 当前页拼图约728.64毫秒 + 少量投影开销。

4查询搜索约750毫秒 = 原始召回约30.54毫秒 + 当前页拼图约719.01毫秒 + 少量投影开销。

当前缓存只覆盖原始MapTools结果，宿主拼图每次仍生成，因此缓存命中后搜索仍需约0.72秒。此处是明确的工具侧重复开销，但即使完全消除，也不能解决十几秒一次的模型请求等待。

## 评估结论

当前主要等待发生在Sonnet请求，减少无效模型轮次仍是第一优先级；工具侧主要可见开销是重复证据板与拼图生成。list_scene、缓存后的工具读取和CLIP文本前向本身都不是秒级主瓶颈。没有理由仅凭本轮数字更换向量模型或移除数据验证。
